# Homeverse — Next.js

Homeverse is a fully responsive real-estate website rebuilt as a standalone Next.js App Router project. It preserves the original design, supplied imagery, smooth section navigation, responsive mobile menu, horizontal property and news feeds, and sticky mobile action bar.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm run start
```

The production build uses Next.js standalone output and can also be launched from `.next/standalone/server.js` after copying the public and static assets required by Next.js.
